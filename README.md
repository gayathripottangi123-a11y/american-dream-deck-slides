# American Dream - Interactive Sales Deck

**Live Demo:** [Will be deployed to Vercel]  
**GitHub:** https://github.com/gayathripottangi123-a11y/american-dream-deck-slides

A Digideck-style interactive presentation for American Dream retail and entertainment destination. Built as a sales tool for leasing agents, sponsors, and event partners.

---

## 🎯 Project Overview

Interactive slide-based sales deck showcasing American Dream's 3 million square foot destination in East Rutherford, NJ. Designed in Digideck format with non-linear navigation and video-first storytelling.

---

## ✨ Key Features

### Digideck Format
- **Slide-Based Navigation** - Card layout with click-to-advance (not scroll-based website)
- **Sidebar Menu** - Jump to any section instantly with thumbnail navigation
- **Progress Tracking** - Visual indicator showing position in deck
- **Keyboard Controls** - Arrow keys for slide navigation
- **Smooth Transitions** - Framer Motion animations between slides

### Video Integration
- **Cinematic Intro** - Auto-playing video background on opening slide
- **Events Video** - Immersive background video on events platform slide
- **Custom Player** - Professional video integration with HTML5

### AI-Generated Assets
- **5 Photorealistic Images** - Created with Leonardo.ai
- **Professional Quality** - Luxury interiors, aerial views, attractions
- **Seamless Integration** - Optimized with Next.js Image component

### Interactive Elements
- **Non-Linear Navigation** - Click sidebar to jump to any slide
- **Arrow Navigation** - Forward/back buttons + keyboard support
- **Active State Tracking** - Highlights current slide in sidebar
- **Responsive Design** - Desktop and tablet optimized

---

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel
- **AI Tools:** Leonardo.ai

## 📊 Slide Structure

1. **Intro Slide** - Video hero with key stats (3M sq ft, 450+ tenants, 40M visitors)
2. **Destination Slide** - Location, demographics, transportation access
3. **Retail Slide** - 450+ tenants, luxury brands, 0% tax highlight
4. **Entertainment Slide** - Nickelodeon Universe, DreamWorks, Big SNOW
5. **Events Platform Slide** - Concert venues, brand activations, corporate events
6. **CTA Slide** - Partner opportunities (leasing, sponsorships, events)

- Black & white color palette
- Premium typography
- High-impact imagery
